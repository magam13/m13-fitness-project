## Предлагаемое требование FR-21

Система должна позволять авторизованному пользователю сформировать CSV своей истории за период от 1 до 31 календарного дня включительно. Границы выбираются по дате запланированного занятия в часовом поясе профиля. В файл включаются только тренировки со статусом «выполнена» или «частично выполнена», по одной строке на workoutId. Столбцы: workoutId, scheduledAt с часовым смещением, status, plannedSets и completedSets. Числа подходов суммируются по WorkoutExercise; текущие статусы и отметки берутся на момент экспорта. Формат — UTF-8, разделитель — точка с запятой, порядок строк — по scheduledAt, затем workoutId. При неверном периоде или отсутствии данных файл не создается, показывается причина. Экспорт работает при доступной сети; доступ к чужим данным запрещен.

## Критерии приемки

| Будущий тест | Ожидаемый результат |
| --- | --- |
| TC-23 | Для периода с одной полной и одной частичной тренировкой CSV содержит заголовок и две строки; число подходов совпадает с историей, незавершенное занятие не включается, дубликатов нет. |
| TC-24 | Периоды 1 и 31 день допустимы; 32 дня и начало позже окончания отклоняются. Граничные даты включаются по часовому поясу профиля. |
| TC-25 | При отсутствии подходящих тренировок отображается «За выбранный период нет тренировок»; файл не создается. |
| TC-26 | Без действующей авторизации и при подстановке чужого userId выгрузка отклоняется; строки чужой истории не возвращаются. |

Новые пункты здесь являются предложением. В действующие документы 02–05 они пока не внесены.
