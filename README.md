# Мобильное фитнес-приложение M13

M13 — проект мобильного приложения для планирования тренировок, ведения дневника питания и отслеживания физического прогресса. Система предназначена для спортсменов-любителей и предусматривает сопровождение пользователей тренером, напоминания и управление тренировочным контентом.

## Состояние проекта

Репозиторий содержит проектную документацию. Реализация мобильного приложения не входит в текущее учебное задание.

## Основные возможности

- Регистрация, вход и разграничение ролей пользователей.
- Заполнение фитнес-профиля, выбор цели и уровня подготовки.
- Формирование тренировочного плана и просмотр расписания на неделю.
- Просмотр упражнений, подходов, повторений и описаний техники.
- Отметка выполнения упражнений, сохранение полной или частичной тренировки и истории занятий.
- Ведение дневника питания с учётом калорий, белков, жиров и углеводов.
- Запись веса, замеров, фото и силовых результатов; просмотр динамики прогресса.
- Напоминания о тренировках и внесении показателей прогресса.
- Просмотр прогресса закреплённого пользователя и комментарии тренера.
- Управление упражнениями и шаблонами тренировок, блокировка учётных записей и изменение ролей.

Перечень основан на требованиях из задания 2 и сценариях из задания 3 первого семестра.
